# voiceOS Dashboard

Modern React + TypeScript dashboard for call management and analytics.

## Tech Stack
- React 18 + TypeScript
- Vite
- Supabase (Auth + Database)
- shadcn/ui + TailwindCSS
- Framer Motion

## Quick Start
```bash
cd voiceOS/public_site/Web\ 3
npm install
npm run dev
```

## Environment
Copy `.env` to project root with Supabase credentials.

## Routes
- `/` - Landing
- `/auth` - Login
- `/dashboard` - Overview
- `/dashboard/action-required` - Action items
- `/dashboard/call-logs` - Call history
- `/dashboard/settings` - Settings
